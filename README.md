# Form Login — VELOX Cloud POS

Halaman portal autentikasi & login resmi untuk **VELOX** (Retail POS OS v2.4).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `director@velox.io` (PIN: `888999`)
   - 💼 **Manajer Operasional**: `inventory@velox.io` (PIN: `444555`)
   - 💳 **Kasir Shift**: `cashier01@velox.io` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (VELOX Mart Kemang, VELOX Superstore Gading Serpong, VELOX Express BSD).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../velox-retail-pos/index.html`](../velox-retail-pos/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
